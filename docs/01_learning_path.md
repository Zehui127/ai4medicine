# 学习路线

本学习路线分为三个阶段，每个阶段包含核心目标、建议资源与输出产物。

## 阶段一：基础能力（0–3 个月）

**目标**：掌握 AI 基础与数据分析方法。

- Python 数据分析：NumPy / Pandas / Matplotlib
- 机器学习基础：监督学习、无监督学习、评估指标
- 数学基础：线性代数、概率统计、优化

**输出**
- 练习笔记与小型 Notebook
- 至少 3 篇基础论文摘要

## 阶段二：医学 AI 工具与数据（3–6 个月）

**目标**：熟悉医学数据形态与模型选择。

- 深度学习基础：CNN、RNN、Transformer
- 医学数据类型：影像、临床文本、EHR
- 医疗 AI 评估：偏差、泛化性、公平性

**输出**
- 医学 AI 主题聚类草稿
- 10–15 篇论文阅读与总结

## 阶段三：研究与写作（6–12 个月）

**目标**：形成可执行的研究问题与初稿。

- 复现实验与开源复用
- 研究问题拆解与可行性评估
- 论文写作结构与图表规范

**输出**
- 研究问题清单与优先级排序
- 初步研究计划（方法、数据、评估）
