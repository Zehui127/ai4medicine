# 项目概览

本仓库用于系统性学习 AI 在医学与临床研究中的方法与应用，目标是：

- 构建 AI + 医学研究所需的知识体系与技能结构。
- 以“可检索、可复用”的方式管理论文与笔记。
- 通过阶段性阅读、总结与小实验，逐步收敛到首个研究课题。

## 使用方式

1. 从 `01_learning_path.md` 开始，建立阶段性学习计划。
2. 在 `papers/00_reading_list.md` 中维护论文清单，并在 `papers/01_summaries/` 写摘要。
3. 阅读流程与总结模板见 `03_research_workflow.md` 与 `templates/`。

## 里程碑

- 0–3 个月：完成基础课程与核心工具熟悉。
- 3–6 个月：聚焦医学数据类型与评估方法，建立论文阅读节奏。
- 6–12 个月：从主题聚类中选题，形成可执行的小项目。
