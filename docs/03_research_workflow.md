# 研究流程

本流程用于规范论文阅读、笔记整理与研究问题定义。

## 1. 阅读与筛选

- 每周确定 2–3 个主题关键词。
- 在阅读清单中标注优先级：高 / 中 / 低。
- 优先阅读近三年内综述与高影响论文。

## 2. 结构化摘要

使用 `templates/paper_summary_template.md` 记录摘要，重点关注：

- 研究问题与动机
- 数据集与实验设置
- 方法亮点与局限
- 可复用的实验细节

## 3. 主题聚类

在 `papers/02_topic_clusters.md` 中维护主题分组，并补充：

- 代表性论文
- 关键技术路线
- 当前挑战与开放问题

## 4. 选题收敛

- 每个主题至少阅读 8–10 篇核心论文。
- 汇总研究空白与实际可行性，形成候选题。
- 对候选题进行“数据获取 + 实验成本 + 价值”评估。
